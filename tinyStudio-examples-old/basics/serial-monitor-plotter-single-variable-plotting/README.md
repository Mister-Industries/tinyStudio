# Single variable plotting

Upload this, then close the Serial Monitor and open **Tools → Serial Plotter**. You'll see a beautiful sine wave scrolling across the screen in real-time.

## Open it

- **tinyStudio (web)** — [open this project](https://app.tinystudio.cc/Mister-Industries/tinyStudio-examples/basics/serial-monitor-plotter-single-variable-plotting)
- **tinyStudio (desktop)** — Examples tab → *Single variable plotting*
- **Arduino IDE** — open `serial-monitor-plotter-single-variable-plotting/serial-monitor-plotter-single-variable-plotting.ino`
